# stock-research-sop

[English](#english) | [中文](#中文)

Website: https://zcxzju.github.io/stock-research-sop/

## English

A Codex skill for turning stock, company, or sector ideas into a structured equity research workflow.

It organizes research into four stages:

- monthly chokepoint screening
- quarterly financial review
- pre-buy red-team falsification
- holding-period milestone monitoring

Each full output ends with a compact Mermaid diagram that visualizes the screening, verification, red-team, and monitoring decision path.

## What It Does

Use this skill to:

- convert raw stock ideas, screenshots, notes, company names, or sector themes into a repeatable research SOP;
- screen for scarce, high-leverage supply-chain chokepoints;
- review whether quarterly financials confirm or weaken the thesis;
- red-team the strongest reasons not to buy before entry;
- define holding-period milestones, verification sources, and failure thresholds;
- produce structured tables and a final Mermaid decision diagram.

This skill is for research organization only. It is not investment advice.

## Usage

```text
Use $stock-research-sop to turn a stock idea into a structured screening, review, red-team, and monitoring workflow.
```

## 中文

一个用于把股票、公司或赛道想法整理成结构化股票研究流程的 Codex skill。

它把研究流程拆成四个阶段：

- 月度卡脖子环节初筛
- 季度财务复审
- 买前空头证伪
- 持有期里程碑监控

每次完整输出都会以一个简洁的 Mermaid 图结尾，用来展示从初筛、验证、证伪到持有监控的决策路径。

## 功能

使用这个 skill 可以：

- 把原始股票想法、截图、笔记、公司名称或赛道主题整理成可重复执行的研究 SOP；
- 筛选稀缺、高杠杆的供应链卡脖子环节；
- 复核季度财务是否验证或削弱投资逻辑；
- 在买入前用空头视角寻找最强反证；
- 设置持有期里程碑、验证来源和失效阈值；
- 输出结构化表格和最终 Mermaid 决策图。

这个 skill 只用于研究流程整理，不构成投资建议。
